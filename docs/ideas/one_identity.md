parings should be not by device, but by identity. all trusted nodes for example share one identity. this is in my
opinion (tell me if I'm wrong) the only thing that would properly work in a p2p network, because we cannot prevent a
user from duplicating its keys across devices. instead of fighting this, we make it a feature. a user generates a
identity at one device and instead of pairing a new device he pairs his own devices which essentially copies his keys
over to a new device
